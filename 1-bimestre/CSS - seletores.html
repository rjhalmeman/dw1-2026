🎯 Seletor de ID (#id)

Seleciona um elemento único pelo seu atributo id. É o seletor mais específico.

/* CSS */
#importante {
    font-weight: bold;
    color: #d9534f;
}

✅ Exemplo: Este parágrafo tem ID="importante" e está em negrito e vermelho.

🌐 Seletor universal (*)

Seleciona TODOS os elementos da página. Geralmente usado para resetar estilos padrão.

/* CSS */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

✅ Exemplo: Todos os elementos deste documento herdaram font-family: Arial por causa do seletor universal.

⬅️ Voltar para o sumário

📝 Seletor de elemento (h1, p, div...)

Seleciona todos os elementos de um tipo específico (tag HTML).

/* CSS */
h1 {
    color: blue;
    text-align: center;
}

✅ Exemplo: Este H1 está azul e centralizado

⬅️ Voltar para o sumário

🏷️ Seletor de classe (.classe)

Seleciona elementos pelo atributo class. Pode ser reutilizado várias vezes.

/* CSS */
.destaque {
    background-color: yellow;
    padding: 10px;
}

✅ Exemplo: Este parágrafo tem classe="destaque" e fundo amarelo.

✅ Outro exemplo: Também com classe="destaque".

⬅️ Voltar para o sumário

📂 Seletor descendente (div p)

Seleciona elementos que são descendentes (em qualquer nível) de outro elemento.

/* CSS */
div p {
    color: green;
}

✅ Exemplo: Este parágrafo é descendente direto de div (verde).

✅ Exemplo: Este também é descendente (neto) e fica verde.

⬅️ Voltar para o sumário

➡️ Seletor filho direto (div > p)

Seleciona apenas os elementos que são filhos imediatos (primeiro nível).

/* CSS */
div > p {
    font-size: 18px;
    background-color: #e0f7fa;
}

✅ Exemplo: Este é filho DIRETO - será afetado (fonte 18px, fundo azul claro).

❌ Exemplo: Este é NETO (não filho direto) - NÃO será afetado.

✅ Exemplo: Este também é filho DIRETO - será afetado.

⬅️ Voltar para o sumário

➕ Seletor de irmão adjacente (h1 + p)

Seleciona o elemento que é imediatamente após outro elemento (irmão direto).

/* CSS */
h1 + p {
    text-decoration: underline;
    color: #5bc0de;
}

Título H1

✅ Exemplo: Este parágrafo é o IRMÃO ADJACENTE do H1 (sublinhado e azul).

❌ Exemplo: Este é o segundo parágrafo, não é irmão adjacente.

⬅️ Voltar para o sumário

🔄 Seletor de irmãos gerais (h1 ~ p)

Seleciona TODOS os elementos irmãos que vêm depois de um determinado elemento.

/* CSS */
h1 ~ p {
    font-style: italic;
    color: #f0ad4e;
}

Título H1

✅ Exemplo: Primeiro parágrafo depois do H1 (itálico e laranja).

✅ Exemplo: Segundo parágrafo também é irmão geral (itálico e laranja).

Div não é parágrafo, então não afeta.

✅ Exemplo: Terceiro parágrafo também é afetado.

⬅️ Voltar para o sumário

🔍 Seletor de atributo (input[type="text"])

Seleciona elementos baseado na presença ou valor de um atributo.

/* CSS */
input[type="text"] {
    border: 2px solid red;
    padding: 8px;
    border-radius: 4px;
}

input[type="submit"] {
    background-color: green;
    color: white;
}


✅ O campo de texto tem borda vermelha. O botão submit tem fundo verde.

⬅️ Voltar para o sumário

👥 Seletor de grupo (h1, h2, h3)

Aplica o mesmo estilo a vários seletores diferentes, separados por vírgula.

/* CSS */
h1, h2, h3 {
    text-align: center;
    color: #5cb85c;
}

✅ H1 centralizado e verde

✅ H2 centralizado e verde

✅ H3 centralizado e verde
