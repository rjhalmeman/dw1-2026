# Organize-se para não sofrer...

Antes de tudo, git clone (especialmente se você estiver utilizando o computador da instituição).
 - Abra uma pasta no terminal (Documentos, por exemplo)
 - git clone https://github.com/seuUsuarioGitHub/2bimestre-dw1
 - Feche o terminal que está aberto na pasta Documentos
  


1) Crie uma pasta para seu novo projeto (dentro da pasta 2bimestre-dw1 que foi clonada).
2) Abra essa pasta no vscode.
3) Copie um server.js (modelo)
4) Copie um cliente.html (modelo)
 - o nodejs tem que estar instalado na máquina para os próximos passos
5) Instale as dependências necessárias (npm install express, por exemplo)
6) Suba o servidor. Abra a pasta no terminal e digite node server.js, por exemplo.
7) Execute o cliente.html para ter certeza que tudo funcionou.
8) ... só então comece a modificar para fazer o exercício.




QUANDO TERMINAR
9) abra a pasta clonada no terminal
10) git add .
11) git commit -m "exercício concluído"
12) git push
